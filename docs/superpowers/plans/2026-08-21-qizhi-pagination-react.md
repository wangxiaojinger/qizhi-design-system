# QIZHI Pagination React 实施计划

1. 以失败测试固定分页算法、受控/非受控状态、每页条数、跳转焦点、简洁模式、禁用与无障碍契约。
2. 实现 `Pagination`、类型与样式，复用 `Select`、`Input` 和 QIZHI 图标，并加入 `@wangxiaojinger/qizhi-react` 公共出口。
3. 建立 9 个同源 Demo、代码操作区与 API 表，用 React Island 替换旧静态 Pagination 规范页。
4. 执行组件测试、文档测试、全量测试、类型检查与构建。
5. 在 1440/1024/375 三档真实操作页码、折叠跳转、每页条数、输入跳转、尺寸、简洁、受控总数与禁用状态；检查控制台、溢出和截图。
