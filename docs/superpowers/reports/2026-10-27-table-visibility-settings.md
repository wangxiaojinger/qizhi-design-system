# Table 列设置显隐与内容宽度验收

日期：2026-10-27。

本次范围：列设置仅保留全选和列显隐复选框；移除面板内的移动、列宽输入及恢复入口。表头手柄移动、边界调宽及键盘路径继续保留。示例的恢复布局入口放在开发配置区，公共 Table API 与布局状态格式保持兼容。

面板使用内容固有宽度，取消固定宽度及通用标题最小宽度，保留视口安全上限；名称不换行，列表仅允许纵向滚动。规范、API 说明、同源示例和测试同步更新。

验证记录：

- 宽度回归先失败再通过：旧实现短、长名称均为 320px；改动后在 1440、1024、375px 下，名称变长会撑宽、切回会收窄，6 项专项浏览器测试通过。
- 独立 Table 单元验证：11 个文件、96 项通过。
- 全量测试：Tokens 24 项通过；Vitest 225 个文件、1202 项通过。使用单 worker 和 60 秒测试超时。
- 类型检查、生产构建、API manifest 一致性、脚本语法及差异空白检查通过。

独立 Chrome 验收：7 个测试文件，82 项通过、2 项按项目条件跳过。跳过项为 1024/375 项目中的 1920px 专项，该专项已在桌面项目通过。三档均验证内容撑宽及收窄、名称单行、无横向溢出、显隐保留顺序与宽度、表头移动和调宽、持久化恢复以及弹窗／抽屉交互。验收者及主模型核对完整日志和截图；浏览器工具会话回收导致未保留进程退出码，以最终测试汇总及成功产物作为完成证据。

主模型已核对独立测试证据与提交范围，本次范围验收通过。提交只包含 Table 实现、文档、示例和测试；不推送、不发布包、不部署文档站。
