# Table 列显隐入口与推荐默认值

本次范围：删除属性示例独立的“列设置入口”开关，按钮及气泡标题统一为“列显隐”。visibility 开启显示入口，关闭则卸载入口和面板，再次开启保留布局状态；移动、调宽仍独立启用。旧 settings 类型保留并标记弃用，不再参与入口显示判断。

属性示例及推荐业务初始组合按确认截图配置：开启边框、悬浮高亮、表头、列调宽、两行省略、实际截断全文提示及容器固定列断点；尺寸为 default，其余开关关闭。组合由业务显式配置，通用 Table 的默认 API 行为保持兼容。

- Table 相关单元测试：11 个文件、96 项通过。
- 全量 Vitest：225 个文件、1202 项通过；Tokens 24 项通过。
