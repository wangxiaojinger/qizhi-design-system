# Table 组件内置默认配置

本轮将用户确认的推荐组合落实到 Table 组件本身，而不再只依赖文档 PropsDemo 显式传参。基线为已发布 v0.4.0；该版本不会被覆盖。本轮是下一版本候选，用户授权独立验收通过后仅本地提交，不推送或发布。

最新截图修订：边框和列调宽默认关闭；悬浮高亮、表头、两行省略、实际截断全文提示和容器固定列断点默认开启，尺寸 default。边框、调宽、列移动、显隐、选择、分页和行拖动由业务按需配置。fixedBreakpoint 默认640，空态上下各36px，缺失原始值默认 '-'；加载默认关闭，开启后默认仅遮罩数据区。

覆盖规则：表级 ellipsis=false 允许自然换行，列级 ellipsis 显式配置优先；旧 true/showTitle 单行语义保留，自定义复杂控件不裁切。columnCustomization 逐字段合并，resize 未设置或 undefined 时为 false，true 才开启。fixedBreakpoint=false 关闭窄容器断点，emptyPadding=0 关闭额外留白，emptyCell=null 关闭缺失占位，loading.scope='table' 覆盖默认数据区遮罩。不会推断业务列的固定、权限、金额或日期语义。
