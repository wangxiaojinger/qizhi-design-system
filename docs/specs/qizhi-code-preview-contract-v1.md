# QIZHI CodePreview API 契约 v1

状态：已审定  
负责人：QIZHI Design System  
证据日期：2026-09-07

## 1. 目标与边界

`CodePreview`（代码预览）用于只读展示代码和结构化文本，支持语法着色、行号、
自动换行、复制、下载和内部滚动。v1 不提供编辑、保存或执行能力。

## 2. 公共 API

公共属性以 `CodePreviewProps` 为唯一类型来源。默认语言为 `text`，默认展示行号
与复制入口，默认不换行、不展示下载入口。状态优先级为加载、空内容、正文。

支持 `javascript`、`typescript`、`jsx`、`tsx`、`json`、`yaml`、`markdown`、
`shell`、`python` 和 `text`；运行时未知值安全回退为纯文本。

## 3. DOM、状态与无障碍

- 公共根类为 `.qizhi-code-preview`。
- 代码视口可通过键盘聚焦，长内容在视口内部滚动。
- 复制按钮名称为“复制代码”，结果通过 `role="status"` 反馈。
- 下载入口名称为“下载代码”，文件名来自 `fileName`。
- 加载状态名称为“正在加载代码”，空状态默认文案为“暂无代码”。
- 组件样式使用 QIZHI 语义 Token 与 `--font-mono`。

- 加载、空内容与正文优先级；
