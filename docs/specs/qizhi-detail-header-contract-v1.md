# QIZHI DetailHeader v1 契约

## 旧站内容

- 页面标题：`详情头部`
- 页面说明：`用于详情页顶部集中展示对象身份、服务状态、关键属性、审计信息与页面级操作，并承接详情内容页签。`
- Demo 顺序：`基本用法`、`交互说明`。
- 基本用法说明、所有字段、时间、版本表格、页签和面板文案保持旧站原文与顺序。
- 交互说明保留四条原文，不作为第二个可复制 Demo。

## 公共边界

- 新增公共 `DetailHeader`，负责详情头部语义结构、身份图形、标题、状态、属性、审计区、操作区和页签槽位布局。
- 状态由 Demo 受控；组件不内置上线或下线业务逻辑。
- Demo 必须复用 `Button`、`Tooltip`、`Avatar.Group`、`Avatar`、`Tabs`、`Drawer`、`Table`、`Link` 和图标库，不得使用原生交互标签或自绘 SVG。
- 实际 Demo TSX 是预览、展示代码和复制代码的唯一来源。

## 视觉与交互

- 主卡最小高度 174px，主区间距 24px、内边距 16px 24px 0，身份图形显示 58px。
- 默认 `服务中`；按钮 `下线`。切换后为 `已下线` 与 `上线`，可再次恢复。
- `V1` 打开 960px 版本列表 Drawer；保留三行数据及禁用状态。
- Tooltip、头像、Tabs、Drawer 的鼠标、键盘、关闭和焦点恢复路径使用公共组件语义。
- 1440、1024、375 三档保持无横向溢出；右侧目录包含基本用法、交互说明和 API。

## MCP 业务接入

- `ServiceDetailHeader` 统一提供创建人、创建时间图标的 hover/focus 提示，提示仅显示字段名称，不包含具体值。
- `headerProps` 仅开放基础头部的 className、status、action、tabs，供业务保留其布局和状态操作，不能覆盖公共审计区。
- serviceId、framework、maintainers 可省略；ID 和框架均省略时，将部署版本入口放在审计行。
- `version` 为受控部署版本；`versionReadOnly` 让版本列表只读，不触发回滚或版本变化。原 Demo 保留原有回滚行为。
- MCP 当前仅有单条版本标识，尚无历史版本、构建时间和构建操作人数据；缺失项显示 `—`，不从服务更新时间和创建人推断。
