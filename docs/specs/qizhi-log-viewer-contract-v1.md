# QIZHI LogViewer API 契约 v1

状态：已审定  
负责人：QIZHI Design System  
证据日期：2026-09-07

## 1. 目标与边界

`LogViewer`（日志查看器）用于观察持续变化的运行日志，支持本地搜索、等级筛选、
手动刷新入口、暂停跟随和长日志浏览。组件不请求接口，不创建轮询、SSE 或
WebSocket，也不包含 Modal（弹窗）外壳。

## 2. 数据和状态所有权

调用方通过 `LogEntry[]` 提供日志，并通过 `loading`、`refreshing` 和 `status`
提供运行状态。`onRefresh` 只通知调用方开始刷新；`refreshing=true` 时刷新按钮
加载并禁用。搜索和等级筛选只处理已传入的数据。

`autoFollow` 传入时为受控状态，未传时默认开启内部跟随。用户离底部超过 24px
后暂停跟随；点击“继续跟随”恢复并滚动到底部。

## 3. DOM、视觉与无障碍

- 公共根类为 `.qizhi-log-viewer`，日志区域使用 `--font-mono`。
- 工具区复用 QIZHI Input、Select、Button、Tooltip 和图标。
- 日志视口可聚焦并在内部滚动，等级通过文字和颜色共同表达。
- 刷新按钮名称在刷新期间变为“正在刷新日志”。
- 加载、空内容和日志正文按此优先级渲染。

## 4. 测试矩阵

- 时间、等级、内容和行号；
- 搜索、等级筛选与无结果；
- 刷新回调、加载禁用和防重复；
- 追加日志、自动跟随、暂停与恢复；
- 空状态、错误状态和无网络请求；
- 1440、1024、375 三档几何、键盘、滚动、控制台和截图。
