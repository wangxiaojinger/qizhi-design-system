# 启智 React（用户界面开发库）图表组件整体设计方案 V1

状态：林猫猫已于 2026-09-09 确认，进入实施与验证。  
日期：2026-09-09。  
交付对象：启智 React 组件系统；业务页面只使用启智公共图表组件。  
本文中的尺寸、默认值、接口和示例文案已经用户确认；实现与验证结果另行记录，设计确认不等于功能已通过验收。

## 1. 目标、事实与设计决策

### 1.1 已确认需求

- 分类为“基础组件 → 数据展示 → 图表”，侧导航到“图表”为止。
- 页面内提供折线图的基础、多系列示例，以及柱状图的普通、分组、堆叠示例。
- 支持请求量、费用的时间趋势，以及输入与输出用量的构成对比。
- 业务页面传入数据；请求量统计、计费、输入与输出用量计算留在业务层。
- 包含悬停提示、图例、坐标轴、单位格式化、加载、空数据、错误、响应式和可访问性。
- 颜色、字体、间距、提示框服从启智规范；底层引擎默认样式不构成设计依据。
- 公共导出、类型定义、接口文档、示例、展示及复制源码、测试同步交付。
- AntV G2（蚂蚁可视化图表引擎）作为首选验证方案，验证后再决定是否采用。

### 1.2 当前已核对事实

- React 工作区位于 `.worktrees/button-react-island`，已有正式组件包、文档、类型检查、单元测试和浏览器测试工具链。
- 当前公共入口未发现折线图、柱状图或通用图表组件导出；这是新增能力，不是已存在组件的换皮。
- 现有表格和数值显示位于“数据展示”，进度条位于“反馈”。本方案将进度条移到“数据展示”列为明确的导航变更，保留原锚点与全部示例，不默认为已完成。
- 当前统计组件导航名称是“数值显示 Statistic（统计数值）”。本次建议保留现有名称，不额外引入改名范围。
- 用户给出的 `http://127.0.0.1:5188/#component-tree` 指向树组件锚点；本次浏览器访问连接被拒绝，未取得在线页面内容或截图。
- 尚无真实业务页面的图表截图、接口字段和数据样本。本方案业务示例来自用户已明确的场景，全部采用标注的演示数据，不能称为真实页面复刻。

### 1.3 推荐的公共组件边界

| 层级 | 本次放置内容 | 职责 |
|---|---|---|
| 基础组件 | LineChart（折线图）、BarChart（柱状图） | 接收数据，完成绘制、图例、提示、格式化、状态和可访问性 |
| 业务组件 | 本次不新增 | 以后有稳定业务口径时，再沉淀用量分析、费用分析、请求监控模块 |
| 平台框架组件 | 本次不新增 | 承载导航与页面布局，允许其内容区使用图表 |

“趋势图组件”在本方案中指这一组可复用的图表能力。推荐对外提供两个明确组件，内部共享数据校验、主题、状态和引擎适配；不再额外导出一个功能重叠的 TrendChart（趋势图）组件。

图表使用传入名称显示简洁标题，不内置指标统计卡、时间筛选、刷新请求或业务明细表。业务页面使用启智现有组件组合这些内容；文档示例标题不作为内部固定文案。

## 4. 视觉规范与组件复用

### 4.1 视觉结构（候选）

- 图表宽度跟随父容器，默认绘图区高度 280 像素；图例、数据查看入口和展开的数据表位于绘图区之外。
- 2026-09-10 按用户指定设计稿统一为浅灰渐变卡片、8 像素圆角、顶部和左右 24 像素、底部 16 像素内边距；公共名称同时用作 14 像素半粗标题。
- 纵轴在左、横轴在下；只显示必要的水平网格线，弱化坐标轴装饰。
- 折线采用设计稿的平滑实线，线宽 2 像素；采用单调插值，缺失仍断开，提示值始终来自原始数据。
- 普通柱状图每分类一柱；分组并排；堆叠累计。柱宽随可用空间计算，保留分类间距，不以拉伸容器制造横向溢出。
- 所有首批数值轴包含零，正负值两侧分别展示；堆叠正负值分别累计，不互相抵消。负值只是通用数值能力，不表示费用场景允许负值。
- 多系列使用一致的颜色顺序；折线统一实线，通过文字图例、可筛选系列和可访问数据表提供非颜色信息；柱状图还保留稳定位置。

### 4.2 设计变量映射

| 部位 | 已有启智来源 | 候选规则 |
|---|---|---|
| 第一系列 | `--chart-series-1`（图表蓝色） | 对应设计稿 #3366FF |
| 第二系列 | `--chart-series-2`（图表绿色） | 对应设计稿 #00E096，不赋予业务状态含义 |
| 扩展系列 | `--chart-series-3` 至 `--chart-series-7`（图表系列色） | 黄、紫、橙、红、粉；声明顺序稳定，隐藏不重排 |
| 正文与提示文字 | `--color-text-1`、`--color-text-2`（主、次文字色） | 沿用语义文字色 |
| 网格与坐标 | `--chart-grid`、`--chart-axis`（图表网格与轴线色） | 浅色实线，坐标文字使用 `--chart-text`（图表文字色） |
| 提示背景 | `--color-bg-popup`（浮层背景） | 与启智现有浮层一致 |
| 字体 | `--font-sans`（无衬线字体）、`--line-height-regular`（常规行高） | 继承启智字体，不采用引擎默认字体 |
| 圆角与阴影 | 现有浮层圆角、阴影变量 | 与现有浮层最终样式核对后复用 |
| 图例与提示间距 | 当前没有确认可直接复用的通用间距变量 | 建议补充图表语义变量，候选间距 8／12 像素；不借用表单专属变量冒充通用变量 |
| 坐标文字字号 | 图表语义变量待登记 | 候选 12 像素，提示正文 14 像素；不改变全局字体基线 |

新增图表语义变量须登记在 `packages/qizhi-tokens/src/tokens.json`（设计变量清单）中，经本方案审定后再写入。不得在图表内部散落无来源颜色、字号与间距。自定义数据色也只能引用已登记变量。

### 4.3 现有组件复用表

| 需求 | 复用来源 | 边界 |
|---|---|---|
| 加载反馈 | Spin（加载中） | 图表容器保留高度，清楚标记加载状态 |
| 无数据 | Empty（空状态） | 文案“暂无数据”，不增加业务操作 |

| 可访问数据表 | Table（表格） | 展示同源数据，不在示例里自造表格组件 |

| 悬停提示 | 现有浮层视觉规范 | 数据点锚定能力需验证；无法直接复用现有 Tooltip（文字提示）时，在图表内部适配，不用示例私有样式实现 |

## 5. 公共接口草案

本节为推荐接口，供确认后形成正式契约。机器代码标识符保持合法英文，中文说明逐项对应；不暴露 G2（底层引擎）的配置对象、实例或类型。

### 5.1 组件与数据类型

- LineChart（折线图组件）。
- BarChart（柱状图组件）。
- ChartDatum（图表数据点）：`x`（分类／时间键，字符串）、`series`（系列键，字符串）、`value`（数值，数字或空值）。
- ChartSeries（图表系列）：`key`（稳定系列键）、`label`（可读系列名称）、`colorToken`（可选的已登记颜色变量）。
- LineChartProps（折线图属性）、BarChartProps（柱状图属性），共用内部属性定义。

使用长表数据形式，每一条记录表示“某个时间点／分类的某个系列值”。使用独立系列声明固定名称、顺序与颜色映射，避免筛选后颜色重新分配。

### 5.2 公共属性

| 属性及中文含义 | 类型 | 默认值 | 行为与边界 |
|---|---|---|---|
| `data`（数据） | 只读数据点数组 | 必填 | 外部提供原始显示值，组件不请求、不计费、不统计业务指标 |
| `series`（系列） | 只读系列声明数组 | 必填 | 固定图例顺序及颜色；系列键唯一，数据只能引用已声明键 |
| `label`（图表可访问名称） | 字符串 | 必填 | 用于图表区域及数据表的可访问名称，同时显示为卡片标题 |
| `unit`（统一单位） | 字符串 | 空 | 轴说明与提示／数据表使用同一单位；每张图首批只支持一个单位 |
| `xFormatter`（横轴文本格式化） | 字符串到字符串的函数 | 原样显示 | 只改变显示文字，不改变排序、原始键与分组 |
| `valueFormatter`（数值文本格式化） | 数字到字符串的函数 | 中文地区数字格式 | 统一用于纵轴、提示、数据表；不改变参与绘图的数值；单位由组件追加，函数不重复返回单位 |
| `legend`（显示图例） | 布尔值 | 开启 | 图例支持隐藏／恢复系列；关闭图例时恢复全部系列，避免数据被隐藏且无法恢复 |
| `tooltip`（显示数据提示） | 布尔值 | 开启 | 控制悬停、触摸与键盘的数据提示；关闭后仍可查看数据表 |
| `loading`（加载状态） | 布尔值 | 关闭 | 隐藏旧数据绘图与交互，保留绘图区高度，避免旧值被误认为新值 |
| `error`（业务错误信息） | 字符串 | 无 | 非空时显示错误；业务页面决定何时清除，不内置网络重试 |
| `height`（绘图区高度） | 正有限数字，单位像素 | 280 | 不包括图例和数据表；非法高度触发开发校验，不静默制造布局异常 |
| `className`（根容器类名） | 字符串 | 无 | 仅用于外部布局，不允许穿透私有节点改变模式 |
| `id`（根容器标识） | 字符串 | 自动生成内部关联标识 | 用于必要的文档或可访问关联，多个实例不得冲突 |
| `ref`（根容器引用） | 元素引用 | 无 | 仅返回根元素，不返回底层引擎实例 |

- 不在首批开放任意 `style`（内联样式）或引擎配置透传，以免绕过设计变量与公共契约。
- “查看数据”默认提供，首批不开放关闭该可访问入口的属性。
- 数据、加载与业务错误由外部控制；系列显隐为组件内部状态。首批不提供受控系列显隐接口，后续有图表联动需求再审定。
- 引擎渲染失败使用固定错误文案“图表暂时无法显示”；保留有效数据的查看入口。数据更新或重新挂载可再次尝试，不循环自动重试。

### 5.3 柱状图专属属性

| 属性 | 值 | 默认值 | 规则 |
|---|---|---|---|
| `mode`（模式） | `normal`（普通）、`grouped`（分组）、`stacked`（堆叠） | `normal`（普通） | 普通只允许一个系列；多系列必须明确选择分组或堆叠，不能重叠绘制或静默求和 |

本次不提供百分比堆叠、双轴混合图、面积图、缩放刷选、数据导出、自动轮播、实时流式刷新或业务钻取。普通／分组／堆叠均为正式公共模式，不能只在示例里改样式模拟。

## 6. 数据语义与交互契约

### 6.1 数据规则

- 横轴顺序以输入数据中分类键的首次出现顺序为准；业务层负责时间排序、时区、粒度和区间补齐，组件不猜测日期格式。
- 同一分类、同一系列只允许一条数据；重复项、未知系列、非有限数字属于数据错误，不静默聚合或丢弃。
- 空值表示缺失，折线断开、柱形不绘制；数值 0 是有效值。只有空值的完整数据集进入无有效数据状态，文案“暂无有效数据”，与空数组区别记录。
- 某分类缺少一个已声明系列时，按该系列缺失处理，不视为零；可访问数据表同样展示“暂无数据”。
- 内部堆叠累计只是绘图几何计算，不产生业务汇总指标；不把缺失分量的部分合计当成完整总量展示。
- 格式化结果仅以安全文本渲染；特殊字符或恶意标记不能注入页面。
- 原始数组不可变，不就地排序或修改业务数据。

### 6.2 提示与图例

- 折线提示以横轴分类聚合，显示该分类所有当前可见系列；柱状图也按分类展示明细，避免只读到堆叠的一段。
- 提示包含格式化的日期／分类、系列名称、数值与单位；首批不默认显示总计、占比或同比环比。
- 鼠标悬停展示，移出后关闭；触摸点击可定位，点击空白或按退出键关闭。
- 提示位置根据视口与实际裁切容器调整，不允许被示例圆角容器裁掉；不只检查提示框自身坐标。
- 点击图例或按回车／空格切换对应系列；隐藏后图例呈非选中态，保留可读名称与焦点。
- 建议保留至少一个系列可见；最后一项不再隐藏，提供可访问说明。关闭图例属性时恢复全部系列。
- 隐藏系列不重新分配剩余系列颜色；堆叠随当前可见系列重算绘图位置，不改原始业务数据。

### 6.3 状态优先级

建议顺序：业务加载中 → 业务错误 → 数据校验错误 → 空数据／无有效数据 → 正常绘制；正常绘制发生引擎错误时显示渲染错误。

| 状态 | 文案 | 绘图与图例 | 数据查看 | 恢复路径 |
|---|---|---|---|---|
| 加载中 | 正在加载 | 暂不显示，保留高度 | 暂不可用，防止显示旧数据 | 外部关闭加载 |
| 业务错误 | 外部提供的错误文本 | 不显示 | 暂不可用，防止使用过期数据 | 外部清除错误并提供数据 |
| 数据错误 | 图表数据格式有误 | 不显示，不静默修复 | 不展示误导性表格 | 外部修正数据 |
| 空数组 | 暂无数据 | 不显示 | 无数据，无展开入口 | 外部传入数据 |
| 全部缺失 | 暂无有效数据 | 不显示曲线 | 允许查看缺失记录 | 外部补充有效值 |
| 正常 | 无状态占位 | 正常显示 | 可展开／收起同源表格 | 更新数据时保持有效焦点 |
| 引擎错误 | 图表暂时无法显示 | 移除损坏绘图 | 有效数据表仍可访问 | 数据更新或重新挂载后重试 |

## 7. 响应式与可访问性

### 7.1 响应式

- 验收视口为 1440、1024、375 像素；同时检查图表实际父容器宽度，不能把视口宽度当成图表宽度。
- 宽度变化重新布局绘图区；隐藏页面重新显示、容器由零宽变为可见、侧栏展开收起后均正确重算。
- 窄屏减少可见横轴标签，优先保留首尾，不删原始数据点；长标签省略后通过提示与数据表获得完整内容。
- 图例允许换行；提示换行并限制在可见范围。图表和页面无横向溢出，数据表可在自己的容器内滚动。
- 布局变化与加载切换保留绘图区高度；更高或更矮的图表由公开高度属性决定。

### 7.2 键盘与辅助技术

- 图表区域具有可访问名称；画布绘图不作为唯一信息来源。
- 提供一个绘图区键盘入口；左右方向键移动分类位置，起始／结束键跳至首尾，退出键关闭提示。焦点样式清晰可见。
- 图例使用语义按钮并表达按下状态；制表键可顺序到达图例及查看数据按钮，不给每个数据点都增加一个制表停靠点。
- “查看数据”展开与图形同源的启智表格，列为日期／分类及系列值；保持单位与格式一致。收起后焦点回到触发按钮。
- 加载使用忙碌状态，错误与状态变化提供适当朗读；鼠标移动不高频播报，键盘定位才播报当前分类摘要。
- 关闭提示不丢失焦点，数据变化后修正已失效的分类索引。
- 默认不依赖装饰动画；尊重系统减少动态效果设置。
- 键盘提示、读屏结构和非颜色信息必须实测，不能只因为引擎宣称支持交互而认定可访问性通过。

## 8. G2（底层引擎）验证方案

这是设计确认之后的验证阶段，不是当前已完成的结论。推荐先制作内部最小验证，再确定正式接入；若关键验证不通过，记录能力缺口并调整方案，不自行更换引擎或扩大依赖。

| 验证项 | 必须取得的证据 |
|---|---|
| 五种展示形态 | 单／多折线、普通／分组／堆叠柱形按同一数据契约正确渲染 |
| 空值和堆叠 | 断线不跨缺口，零值正确，正负堆叠正确，缺失分量不假装为零 |
| 启智主题 | 字体、数据色、轴、网格、图例与提示均由启智控制，无默认主题残留 |
| 公共边界 | 业务与文档示例只导入启智组件；公共类型不引用引擎类型 |
| 提示与键盘 | 悬停、触摸、键盘能够获得等价数据，关闭路径和焦点正确 |
| 生命周期 | 重复挂载、卸载、数据替换、快速切换、渲染失败、尺寸变化后无重复画布或残留监听 |
| 隐藏容器 | 文档路由切换后图表尺寸恢复，不出现零宽画布 |
| 包体与加载 | 记录新增依赖体积、实际构建体积和图表加载方式；普通页面不因未使用图表就执行引擎初始化 |
| 性能 | 记录机器环境，测试 7、31、1000 个分类及多系列场景的绘制与更新；数据量仅为测试点，不据此宣称无限数据能力 |
| 发布消费 | 构建后在消费应用中从启智包导入，与文档源码别名运行结果一致 |

验证通过后，内部引擎由组件包管理；业务页面不创建引擎实例、不拼引擎配置、不接收引擎事件对象。组件包内部允许引擎使用画布或矢量绘图，但示例和业务页不能自行绘制替代公共组件。

参考资料（仅证明引擎接口，不证明启智实现已通过）：[G2 官方接口文档](https://g2.antv.antgroup.com/manual/api)、[G2 官方提示信息文档](https://g2.antv.antgroup.com/manual/component/tooltip)。
