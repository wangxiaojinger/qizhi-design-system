# QIZHI 分析时间控件契约 v1

状态：接入候选。业务统计口径见 Qways 前端界面工程规范 §3.4。

| 能力 | 证据 | 契约 |
| --- | --- | --- |
| 快捷范围和直接输入 | 用量页改造要求 | 复用 Button、Popover 和 Input，点击快捷项或应用后才提交 |
| 聚合粒度 | 用量页改造要求 | 复用 Select，显示自动模式的实际粒度，粒度名称及可用性由业务配置 |
| 图表拖选 | QIZHI 折线与柱状图、用量页改造要求 | 每张有数据的时间序列图启用绘图区拖选，预览起止时间并允许选择小于当前展示桶的范围 |
| 月粒度与性能限额 | 业务后端的聚合能力 | 由接入项目配置并由其服务端校验 |

## 导出和数据

- `DateTimeRangePicker` 使用受控的 `value` 与 `onChange`。范围为毫秒时间戳 `{start,end}`，结束不含。统计时区默认为 UTC，可传有效的 IANA 时区。控件按该时区显示与解析时间，默认文案省略时区后缀。快捷项的 `resolve(now)` 使用一次当前时刻计算范围。
- 输入支持到秒并按统计时区解析。无效、重复或不存在的当地时间提示修正。业务可用 `validate` 返回错误文字以阻止提交，组件保持草稿和上次有效值。外部关闭或取消丢弃草稿。范围或时区更新使面板关闭时，如果焦点仍在面板内且触发按钮可用，焦点回到触发按钮。
- `GranularitySelect` 使用受控的 `value`、`onChange`。业务提供可选粒度及禁用状态，使用 `resolvedValue` 展示自动模式当前采用的粒度。选中模式后由页面决策、更新查询。
- `LineChart` 和 `BarChart` 自动识别按时间顺序排列的 ISO 日期或时间戳。时间轴默认支持拖选，分类轴不启用。日期仅作为分类标签时，设置 `xAxisType="category"`。通过 `rangeSelection={false}` 可关闭时间轴拖选。
- 单图默认在松手后缩小可见范围，并提供「重置时间范围」。继续框选时，选区限制在上一次提交的范围内。缩放后只剩一个时间戳时，仍可在上一次选定的范围内继续框选，数据点的绘制位置与选区时间对应。单柱的时间戳等于范围起点时，柱子对齐可选区起点。页面级联动使用 `rangeSelection.onChange` 接收毫秒时间范围 `{start,end}`，按 `[start, end)` 查询。页面可传 `timeDomain` 覆盖可选边界。拖选期间边界或对齐步长改变时取消当前手势。提交使用当前的回调。折线图按点映射时间，柱状图按时间桶映射。传入查询的完整结束边界后，折线图为末桶保留可连续拖选的绘图宽度。未传边界时，日期键按一天、等间隔时间戳按采样间隔推断末桶；不等间隔时间戳仅保证包含最后一条记录。业务已知桶结束时间时应传入该边界。
- 选区显示精度 `precision` 默认到秒，可配置为毫秒或分钟。默认按 UTC 取值并省略时区后缀，可用 `resolveStep` 按未对齐选区动态选择步长，预览与提交共用该步长。可传 `formatTime` 自定义显示格式和时区。`timeDomain.step` 可独立声明可查步长（毫秒），开始向下对齐，结束向上对齐，并限制在可选时间域内。
- 用量示例手动粒度保持不变。自动模式在小时限额内可以缩到小时级，选区超过小时限额时按可用的自然日边界查询，并提示边界调整。校验拒绝时显示原因并保留上次有效范围。
- 横轴按时间跨度简写标签，并根据绘图区宽度选取可容纳的刻度间隔。悬停提示和拖选预览默认统一显示到秒，费用示例保留足够的小数位以区分纵轴刻度。业务仍可通过 `xFormatter` 和 `valueFormatter` 自定义显示。

## 交互与验收

焦点、可访问命名和弹层键盘操作复用 QIZHI 基础组件。键盘和触屏可通过时间选择器完成图表同等查询。验证快捷项、草稿取消、非法范围、夏令时、手动切换、正反拖选以及现有图表焦点行为。官网演示使用正式包导出，示范应用管理查询状态。
