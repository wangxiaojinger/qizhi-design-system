# QIZHI Admin Design System v1.1.0

`v1.1.0` 扩展了中性企业后台规范：完整浅色/深色 Token、灰阶主控件、Ant Design 主题桥接与 `ConfigProvider` 组件配置现在都由 QIZHI 正式包提供。

## 变化

- `@wangxiaojinger/qizhi-tokens` 覆盖后台的排版、间距、布局、图表、侧栏、状态、焦点、抽屉和深色模式 Token。
- 全局主操作、选中、焦点和控件强调色固定为中性灰；蓝色只保留给信息语义或图表数据。
- `@wangxiaojinger/qizhi-react` 提供完整 Ant Design ThemeConfig、Drawer/Form/Table 等组件配置，以及 `@wangxiaojinger/qizhi-react/theme` 的只读 Token 工具。
- Inspire ITA 后台作为首个使用该正式包的项目。

## 升级

```bash
pnpm add @wangxiaojinger/qizhi-tokens@1.1.0 @wangxiaojinger/qizhi-react@1.1.0
```

在应用根入口导入 `@wangxiaojinger/qizhi-react/style.css`，并用 `QizhiProvider` 包裹应用。需要保留旧规范的项目可继续精确锁定 `1.0.0`。
