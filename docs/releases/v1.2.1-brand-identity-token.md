# QIZHI Admin Design System v1.2.1

`v1.2.1` adds the public `admin.brand.identity` Token for shared product branding without changing the neutral enterprise-admin primary-control contract.

## Added Token

| Token | CSS variable | Light | Dark |
| --- | --- | --- | --- |
| `admin.brand.identity` | `--admin-brand-identity` | `#3366ff` | `#6690ff` |

Use this Token for brand identity surfaces and marks. It does not replace `admin.primary`, `control.accent`, or Ant Design `colorPrimary`, which remain neutral by design.

## Upgrade

```bash
pnpm add @wangxiaojinger/qizhi-tokens@1.2.1 @wangxiaojinger/qizhi-react@1.2.1
```
