# QIZHI Admin Design System v1.0.0

v1.0.0 是一次不兼容升级：QIZHI 从蓝色自研组件库切换为中性企业后台 Token 与 Ant Design 组件体系，**不提供旧 API、旧 CSS 类、图标入口或 Token 的兼容层**。

## 新的使用方式

```tsx
import "@wangxiaojinger/qizhi-react/style.css";
import { Button, QizhiProvider } from "@wangxiaojinger/qizhi-react";

export function App() {
  return <QizhiProvider><Button type="primary">保存</Button></QizhiProvider>;
}
```

安装时同时添加 Ant Design peer dependencies：

```bash
pnpm add antd @ant-design/icons @wangxiaojinger/qizhi-tokens@1.0.0 @wangxiaojinger/qizhi-react@1.0.0
```

## 升级步骤

1. 保留旧项目锁定的 v0 包版本，直到完成迁移；不要让 v0 自动升级到 v1。
2. 删除旧的 QIZHI 自研组件、图标子路径、旧 CSS 类和兼容 Token 引用。
3. 以 `QizhiProvider` 包裹应用，改用 `@wangxiaojinger/qizhi-react` 的 Ant Design 导出或直接导入 `antd`。
4. 将页面样式改为 v1 `--admin-*`、`--text-*`、`--border-*`、`--status-*` 与 `--component-*` 语义 Token。
5. 安装 v1 后重新构建并完成视觉、交互及深色模式验收。
