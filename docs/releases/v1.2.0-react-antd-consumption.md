# QIZHI Admin Design System v1.2.0

`v1.2.0` establishes the currently verified consumer baseline for the QIZHI public packages and clarifies theme ownership without removing existing Provider APIs.

## Verified baseline

- React `19.3.0`
- React DOM `19.3.0`
- Ant Design `6.6.6`

The packages keep their peer dependency ranges for compatible consumers. Versions within those ranges other than this baseline are not validated by this release.

## Provider contract

- `QizhiProvider` retains the public `theme="light" | "dark"` API and its existing theme-mode semantics.
- One `QizhiProvider` owns the Ant Design `ThemeConfig` and QIZHI visual styles for each React root.
- Applications may provide safe non-visual configuration such as locale, direction, component size, prefix classes, container callbacks and Form behaviour. They cannot replace QIZHI ThemeConfig or QIZHI-managed component styles.

## Consumer verification

`pnpm verify` now packs both public packages and installs them into an independent temporary Vite consumer. The consumer resolves the verified React and Ant Design baseline before building, so workspace links cannot conceal package-boundary failures.

## Upgrade

```bash
pnpm add @wangxiaojinger/qizhi-tokens@1.2.0 @wangxiaojinger/qizhi-react@1.2.0
```

Import `@wangxiaojinger/qizhi-react/style.css` once at the application entry point and mount one `QizhiProvider` at the React root. Do not add a second Ant Design `ThemeConfig` owner around it.
