# 图表数据项聚焦验收记录

日期：2026-09-10。范围：启智 React（界面组件框架）公共柱状图、折线图的数据项聚焦。实施者直接完成；独立最终验收 pending（待完成）。

## 实现与变更

共享聚焦钩子管理受控／非受控选择；身份由原始数据的系列键与分类键映射，回调附带当前分类索引及原始对象。图形命中来自 G2（内部图表引擎）绑定数据，不使用页面节点索引。聚焦与提示状态分离，弱化只更新数据图形透明度；引擎不因单纯聚焦切换重建。180 毫秒过渡支持中途取消和减少动态效果偏好。

折线聚焦开启后使用半径3像素实心点及透明描边命中区，右端额外预留3像素保证完整圆点；关闭能力时保留原有外观。普通、分组、堆叠柱均按单个系列数据项选择。单位、日期分布、12像素间距、40／20／10柱宽及无查看数据入口保持。

## 失败证据与修正

- 首先增加公共组件聚焦测试，旧实现4失败、1通过：没有可选数据项或键盘选择能力。
- 文档门禁先2失败、5通过：缺少新增示例与接口。
- 首次浏览器受沙箱限制无法启动，随后以授权的本地浏览器方式运行。
- 测试夹具最初有并发初始化，移除自动初始化；源码热更新曾导致验收页面重载，在源码稳定后复验。
- 连续卸载暴露迟到尺寸回调读取空引用，新增回归测试先失败，随后加入空值检查。
- 业务联动测试误读读屏状态节点，修正为实际业务详情节点。
- 截图发现折线默认空心点在透明描边下不可见；真实引擎填充断言先失败，改为开启聚焦时显示实心点。
- 默认聚焦项未作为初始键盘游标，新增测试先失败后修正。
- 最后一个圆点越过绘图区边界，真实边界断言先失败，增加只在启用折线聚焦时生效的绘制余量。
