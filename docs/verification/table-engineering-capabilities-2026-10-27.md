## 完成能力

- 数字列宽新增独立 shrink、shrinkPriority、growPriority。旧 grow 压缩 fallback 与 compact/auto/非约束行为保留；名称、说明封顶后由显式后级扩展列承接余量，未配置承接列不隐式突破上限。
- 显式 rows/tooltip 文本叶子模式支持两行、按实际截断提示，观察容器、内容及字体变化。旧 ellipsis=true/showTitle 保持原生 title；复杂 render 控件不被新模式限高。
- loading 对象支持 body scope，不移除表头／传入数据；无数据加载不输出误导性空态；布尔 loading 保持旧行为。
- fixedBreakpoint 按 scroller 容器尺寸取消并恢复固定列，不使用 viewport 作为代替。
- emptyPadding 单层控制默认／自定义空态留白；emptyCell 仅处理无 render 的 null、undefined、空字符串，保留真实 0、false、render 业务语义。
- Table loading config 公开类型及 API manifest、12 组既有 Demo/复制代码同步；更新时间继续左对齐。
