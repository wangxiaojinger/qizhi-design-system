# AutoComplete React Island 验证记录

## 实施范围

- 新增 QIZHI `AutoComplete` React 组件、TypeScript 类型、样式和公共出口。
- 按旧站顺序迁移 8 组 Demo：基础用法、自定义选项、自定义输入组件、区分大小写、复杂用法、查询模式确定类目、查询模式不确定类目、自定义过滤规则。
- Demo 源文件同时作为复制代码来源，API 表仅列出组件实际实现的能力。
- 自定义输入复用 QIZHI `Input.TextArea`，复杂提示复用 QIZHI `Popover`，查询图标复用 QIZHI `SearchIcon`。

## 实际检查

- `pnpm test`：175 个测试文件、863 项测试通过。
- `pnpm typecheck`：通过。
- `pnpm build`：文档站、`@wangxiaojinger/qizhi-react` 和消费端 smoke 构建均通过；文档站存在大包体积提示，无构建失败。
- 应用内浏览器实际验收 1440、1024、375 三档：每档均渲染 8 个输入控件；基础候选为 5 项且支持方向键和回车选中；大小写严格模式下 `B` 为 0 项、`b` 为 3 项；确定类目查询为 9 项。
- 三档均检查文档和组件区域无横向溢出；自定义输入组件在 1440/1024 为 320×80px，在 375 视口内收缩为 205×80px。
- 1440 浮层为 320×240px，候选内容超高时在浮层内部滚动；虽然祖先 `.qz-content` 使用 `overflow: hidden`，浮层四边均位于其实际边界内，没有被祖先裁切。
- 1440 与 375 打开态截图已实际查看：输入框、分组标题、候选项、搜索图标、浮层边框和阴影完整可见；375 下浮层左右边界为 85–290px，未越出 375px 视口。
- 应用内浏览器控制台错误为 0。
- 修复文档站 `.doc-section ul` 对候选浮层的左缩进污染；浏览器实测浮层左右内边距均为 4px，候选内容与输入框重新对齐。
