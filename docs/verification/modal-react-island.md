1. 公共规范：Modal、Button、Input、Select、Checkbox、Table 和图标均复用 QIZHI 公共实现及公共结构、类名和间距。
2. 视觉联动：打开、关闭、异步加载、静态方法更新、表格选择和步骤切换均通过真实交互及实际坐标检查。
3. 完整盒模型：核对遮罩、对话框、头部、正文、页脚和视口边界；头部为 `0 24px`、正文为 `16px 24px`、页脚为 `16px 24px`，默认宽度稳定为 520px，移动端为视口减 32px。
4. 无重复造组件：Demo 未自制已有 Button、Input、Select、Checkbox、Table 或图标；通知和步骤内容仅保留旧站特有的 Demo 组合结构。
5. 完整状态路径：覆盖取消、关闭按钮、遮罩关闭、Esc、焦点进入与恢复、异步错误聚焦、加载、Select 浮层、静态更新和自动关闭。
6. 同源：页面运行源码、展示源码和剪贴板内容逐字一致；不存在“复制样式”入口。
7. 消费范围：除独立 Modal 页外，回归验证 Upload 内的 Modal 消费场景；旧脚本排除 React Island，避免重复绑定。
8. 验证证据：同时使用单元测试、计算样式、实际坐标、真实点击、控制台检查和三档局部截图，不以 DOM 存在代替视觉结论。
