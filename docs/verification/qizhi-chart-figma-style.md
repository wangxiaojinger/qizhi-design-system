# 启智图表设计稿样式对齐

日期：2026-09-10。
依据：[Figma（设计稿）节点 19910:261731](https://www.figma.com/design/1QsH8Fs6UEXddl14tGqaRn?node-id=19910-261731)。已读取节点结构与截图；未修改设计文件。

## 对齐内容与范围

| 设计特征 | 公共实现 |
| --- | --- |
| 顶部浅灰向透明渐变、圆角 8 像素 | 公共图表外壳，新增图表专用变量，保留全局基线 |
| 顶部／左右 24 像素、底部 16 像素 | 公共卡片内边距 |
| 14 像素半粗标题，22 像素行高 | 现有 label（名称）同时显示为标题，接口说明同步 |
| 平滑实线 | 内部引擎采用单调平滑，保持缺失分段，不改变原始数据和提示值 |
| 蓝、绿、黄、紫、橙、红、粉 | 七个图表系列变量，精确取自指定节点；隐藏不重排，自定义颜色变量继续可用 |
| 浅色实线网格和底轴 | 网格、轴线与坐标文字专用变量 |
| 底部左对齐图例 | 6 × 2 像素标记，标记到文字 4 像素，系列间距 12 像素，隐藏态透明度 30% |

同一外壳、配色、轴线和图例应用于折线、普通柱状、分组及堆叠柱状。12 个示例的标题、说明、顺序、数据与初始状态保持。手机文档示例外围留白缩为 16 像素，公共操作区的 12 像素间距与零右内边距保留。

## 明确保留的差异

- 纵轴数值和单位保留，支持基础图表直接读数；窄屏日期轴可缩为月日，提示和数据表保留完整格式化结果。
- 默认绘图区仍为 280 像素；业务名称和数据由调用方传入，不复制参考图的请求状态文案与曲线数据。
- 保留已交付的查看数据入口、键盘／触屏提示和状态反馈。指定节点没有提示框，提示框继续沿用启智现有浮层规范。
- 七种颜色属于数据系列色，不将参考图中的状态码语义绑定到公共组件。绿色与红色也不替业务决定成功或错误。
