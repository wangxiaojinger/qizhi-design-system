## 八类问题复核

- 完整规范复用：改为复用 `qizhi-react-demo-codebox`，Demo 到操作区间距固定为 12px。
- 状态与视觉联动：滚动、缩放和尺寸变化会重算浮层位置。
- 完整盒模型：同时检查触发器、浮层、视口、裁切祖先和 Demo/操作区间距。
- Demo 公共能力：8 个 Demo 继续只使用公共 React 组件。
- 完整交互路径：增加重复点击关闭和外部点击关闭回归，保留 Escape 焦点恢复。
- UI/源码/复制同源：展示与复制仍共用 `tsxSource`，并增加剪贴板逐字比较。
- 范围：保留 8 个 Demo、ConfigProvider 消费场景和共享 TimePanel 全量回归。
- 验证结论：改为坐标、计算样式、交互、剪贴板与截图共同判定，不再仅依赖 DOM/类名。
