# 文档刷新阅读位置修复

2026-09-10。范围为 React 文档系统共用路由层。

## 原因和变更

异步 React 章节尚未挂载时，原路由把深层锚点判断为无效并立即替换成概述；原有存储只保存侧导航滚动，没有正文阅读位置。

- `script.js`：未挂载锚点等待 DOM 更新或组件就绪事件；十秒后仍不存在才按无效地址处理。会话存储正文所属面板、章节及相对视口偏移，仅刷新同地址时恢复。正文尺寸与节点更新期间重新定位，用户滚动或操作立即结束恢复；存储不可用仍能正常定位章节。恢复时保护目录同步，避免再次替换地址。最后加入临时禁用浏览器自动滚动补偿与平滑滚动的处理，以排查按钮页四像素偏移。
- `index.html`：同步样式及脚本版本参数为 `20260910-reading-position-001`。
- `tests/e2e/docs-reading-position.spec.ts`：三档图表／按钮／表格刷新、章节直接访问、前进后退、存储不可用与手动滚动检查。

## 证据和限制

原实现桌面两个测试均失败：刷新和直接章节地址都会回到概述。修复后图表阅读位置恢复通过，三档直接章节访问及存储不可用检查曾通过；按钮页仍发现四像素差异。测试中按钮地址曾误用 `component-button`，已修正为实际 `components-button`；平滑滚动采样已改为即时定位。

最后补偿调整后的 `node --check script.js`、`pnpm build`、`git diff --check` 通过。最终浏览器复验连续两次被自动审批服务连接故障拒绝，命令未执行；没有绕过拒绝。最新源码的精确偏移及完整三档结果仍待复验，不能声明全部验收通过。

本地5190固定预览仍为上一轮构建；最新补偿调整尚未同步到该固定预览。独立最终验收待完成。
